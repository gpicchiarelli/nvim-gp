# Support

## Canali

- Bug riproducibili: aprire una issue con il template bug.
- Feature: aprire una issue con il template feature.
- Discussioni architetturali: usare GitHub Discussions quando abilitate.

## Informazioni utili

Includere sempre:

- piattaforma;
- versione Neovim;
- output `:Salute`;
- comando eseguito;
- risultato atteso;
- risultato ottenuto.

Non includere segreti, token, dump database o `.ai/context.md` completi se contengono codice privato.
